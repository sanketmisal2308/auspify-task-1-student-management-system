## Project Description
A responsive web application for managing student records.
The application supports creating, viewing, updating, deleting,
searching, and filtering student information.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser localStorage

## Features
- Student registration
- View student records
- Update student details
- Delete student records
- Search by name, ID, email, or phone
- Filter by department
- Dashboard statistics
- Form validation
- Responsive user interface
- Persistent browser storage

## How to Run
1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Open index.html using Live Server.
4. Add and manage student records.

## Storage
Student records are saved in the browser's localStorage.
This project does not currently use a backend or database.

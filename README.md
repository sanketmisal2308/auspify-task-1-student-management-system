# Student Management System

## 📌 Project Overview
The Student Management System is a simple and responsive web application developed as part of the **Auspify Technologies Software Development Internship – Task 1**.

This application helps users manage student records efficiently through an easy-to-use interface.

## ✨ Features
- ➕ Add new student records
- ✏️ Update existing student details
- 🗑️ Delete student records
- 👨‍🎓 View all student information
- 🔍 Search students by name, ID, email, or phone number
- 🏷️ Filter students by department
- ✅ Form validation
- 💾 Save records using browser Local Storage
- 📱 Responsive user interface

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.

   **Recommended:** Use the Live Server extension in VS Code to run the application.

## 💾 Data Storage
The application uses browser Local Storage to save student records.

**Note:** Student data is stored in the browser on the current device. This project does not currently use a backend server or database.
